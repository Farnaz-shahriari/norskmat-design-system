# design-sync notes, Norsk Mat design system

Repo-specific facts for the next /design-sync run. Read this first.

## Setup

- [GENERAL] The package has no compiled JS entry. `main` points at `src/index.ts`, the build emits only `dist/*.d.ts` and `dist/norskmat.css`. The converter bundles the TS source directly: `cfg.entry` is `src/index.ts`, and the converter is always run with `--entry ./src/index.ts --node-modules ./node_modules`.
- [GENERAL] Run `npm run build` before the converter whenever stories change, not only components. Tailwind scans the whole repo root, so `dist/norskmat.css` is what carries the layout classes the stories and the platform decorator use. A story class missing from the previews means a stale `dist/`.
- [GENERAL] The platform decorator (all four themes side by side, or one theme class on `<html>`) is `.storybook/with-platform.tsx`, listed in EVERY story file's meta `decorators`, not in `preview.tsx`. Why: the converter applies preview-wide decorators with a fixed context (initial globals, no story parameters), so a story pinned to one platform still rendered all four columns in the preview, four open dialogs stacked, all KSL. Meta decorators get the story's own `parameters`. A new story file must list `decorators: [withPlatform]` in its meta.
- [GENERAL] Overlay stories (open Dialog, Select, AlertDialog, Sheet, Tooltip, DropdownMenu, Popover) pin one platform with `...pinPlatform("<id>")` from `.storybook/platforms.ts`. It sets the global (Storybook toolbar lock) and `parameters.platform` (what withPlatform reads, and the only one previews see). Pinned mode wraps the story in `min-h-screen`: the compare harness screenshots `#storybook-root`, and a short root cropped the centred dialog out of the reference.
- [GENERAL] `.storybook/preview.tsx` must not import CSS: the converter bundles it with esbuild, and the fonts behind `preview.css` failed that bundle ("No loader is configured for .woff2"). The stylesheet loads through `previewAnnotations` in `.storybook/main.ts` and `.storybook/preview-styles.ts` instead.
- The npm cache at `~/.npm` has root-owned entries on this machine (EACCES). Installs used `--cache /private/tmp/claude-502/npm-cache` as a workaround. Fix with `sudo chown -R 502:20 ~/.npm`.
- Story title "Tabs" maps to the `TabGroup` export (`cfg.titleMap`); the stories render a whole tab row.

## Decisions

- Fonts, decided by the user on 2026-10-21: accept substitutes for `[FONT_MISSING]`. "Work Sans" and "Poppins" are fallbacks after Manrope in the KSL, Nyt Norge and Spesialitet stacks and never load, since Manrope ships. LokalMat's "Messina Serif" and "Sands" are not licensed; LokalMat renders in Georgia, the stand-in `tokens.css` declares, until real licensed files exist. Do not ship the Messina files found in the hand-built "Norsk Mat Design System" Claude Design project (some are named Trial) without a licence.
- Only storied components become documented components in the storybook shape. 30 components have stories (10 from the original Storybook step, 20 added for this sync); the rest of the library is in `_ds_bundle.js` but undocumented. To document more, write stories for them and re-sync.

## Grading

- [GENERAL] Every story renders inside the platform decorator: four themed columns in an auto-fit grid (min 280px). The preview page pads the story by 24px, so the grid usually wraps at 2 columns in the preview where the reference storybook shows 3 (or 1+3 vs 2+2). That is framing, not the component: grade on the components inside the columns. Cells inside a column can wrap differently for the same reason.
- [GENERAL] The shipped CSS sets no page font: Tailwind's preflight puts `ui-sans-serif, system-ui` on `html`, and `--font-family` only reaches text with a named type class (`label-*`, `body-*`, `title-*`, `headline-*`). Text sized with `text-*` or inheriting (DialogTitle, Select options, Table, Badge ...) renders in the system font in apps and in Claude Design. `.storybook/preview.css` used to set `body { font-family: var(--font-family) }`, which hid it; that line is removed so Storybook shows what apps get. LokalMat columns therefore show system sans for inherited text on BOTH sides; that is the library's bug, not a preview mismatch. Library fix proposed to the user (font-family in each theme block of tokens.css), not applied; decision pending as of 2026-10-22.
- The compare harness captures previews at 900x700. A side-by-side story taller than 700px in the preview's 2-column wrap is cut off at the bottom in the capture only (Card "With Dividers"). Grade on the visible part and the full KSL/Nyt Norge columns.
- The Spesialitet page background (beige) only exists in Storybook (preview.css paints body with var(--background)). Backdrop and page tint differences in Spesialitet stories are framing.
- [GENERAL] When a delta looks width-caused, prove it before calling it framing: render the preview at a viewport that gives the storybook column width (900px storybook -> 948px preview, since the preview pads 24px each side). A throwaway playwright script serving ds-bundle and opening `components/components/<Name>/<Name>.html?story=<Export>` is enough. Used to confirm TextInputField "Trenger utfylling".
- [GENERAL] Horizontally scrolling rows (TabGroup with `scrollable`, Table's overflow wrapper) show less in the narrower storybook columns: TabGroup's disabled "Arkiv" tab and TabLarge's "Vedlegg" scroll out of view, Table hides the Alvorlighet column. Framing; check the story source renders the hidden item on both sides.
- [GENERAL] The shrunk compare sheet invents small colour and icon deltas (LokalMat TabCompact indicator looked grey, Spesialitet ConnectedButtonGroup check looked broken; raw PNGs identical). Open raw/ before grading any small colour or icon difference close or mismatch.
- [GENERAL] Non-modal overlays (Tooltip, Popover) sit 24px further right and down in the preview capture than in storybook: `?story=` captures keep the preview page's `body{padding:24px}`, while modal overlays (Dialog, AlertDialog, Sheet, DropdownMenu, Select) lock scroll and react-remove-scroll-bar zeroes that padding. Framing; the product card already has no body padding. Radix collision avoidance can also place a tooltip differently near the left edge because of the shift.

## Re-sync risks

- Every story file must list `decorators: [withPlatform]` in its meta. A new story file without it renders in the KSL root only and will not match storybook; one pinned without `pinPlatform()` renders four stacked overlays.
- Overlay cards depend on config: `cardMode: "single"` with `primaryStory: "OpenKSL"` for AlertDialog, Dialog, DropdownMenu, Popover, Select, Sheet, Tooltip, and `cardMode: "column"` for DatePicker. Renaming an `OpenKSL` story export breaks that card silently.
- Run `npm run build` AND rebuild `.design-sync/sb-reference` whenever stories or `src/` change; they must move together. `dist/norskmat.css` is what carries story layout classes.
- The page-font bug (see Grading) is still in the library as of 2026-10-22. If `tokens.css` gains `font-family: var(--font-family)` in its theme blocks, inherited text changes on both sides (styling: grades carry, expect a spot-check), and the `fontFamily` root workaround in `.design-sync/conventions.md` should then be removed.
- `.design-sync/conventions.md` names utility classes that exist in the compiled CSS today only because a component or story uses them (incl. `bg-[var(--error)]` and friends, from stories/card and badge). Re-validate every name against the fresh build on each sync; a class that stops being used anywhere drops out of `styles.css`.
- Partially verified: several side-by-side stories are taller than the 700px preview capture, so the bottoms of the Spesialitet/LokalMat columns were judged via the full KSL/Nyt Norge columns (Card "With Dividers", RadioGroup "States", Textarea "States", Accordion "Multiple open"). Sibling-trusted stories exist for Table, Accordion, Breadcrumb, Pagination, ConnectedButtonGroup.
- Toolchain at this sync: Storybook 10.6.1, Vite 7.3.7, @tailwindcss/vite 4.1.11 (must match Tailwind 4.1.11), Playwright 1.64.0 with its Chromium, converter deps esbuild 0.28.2, ts-morph 28.0.0, @types/react 18.3.12 in `.ds-sync/`.
- Guidelines come from `skills/norsk-mat-design-system/references/*.md` (`cfg.guidelinesGlob`), not `docs/`.
- Known library issues found during this sync, unfixed, reported to the user: page font, DatePicker trailing text overflows narrow fields, TextInputField label collapses beside the "Trenger utfylling" chip below ~290px (viewport media query, not container width).
